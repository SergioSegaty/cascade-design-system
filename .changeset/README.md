# Changesets

Hello and welcome! This folder has been automatically generated by
`@changesets/cli`, a build tool that works with multi-package
repos, or single-package repos to help you version and publish your code.
You can find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started engaging with this
tool.

## How do I add a changeset?

Run `pnpm changeset` at the root of the repo. It'll walk you through which
packages changed (`@cascade-ds/components`, `@cascade-ds/styles`) and at
what semver bump, then write a markdown file describing it. Commit that file
alongside your change.

## What do the release scripts do?

- `pnpm version-packages` runs `changeset version` — consumes every pending
  changeset, bumps `@cascade-ds/components`/`@cascade-ds/styles` accordingly
  (bumping the other automatically when one depends on the other, per
  `updateInternalDependencies` below), updates their `CHANGELOG.md`s, and
  deletes the consumed changeset files.
- `pnpm release` builds the DS package and runs `changeset publish`, which
  publishes any package whose `package.json` version isn't already on the
  registry.

## Why don't `@cascade-ds/generator` and `@cascade-ds/storybook` get versioned?

They're listed in `ignore` in [`config.json`](./config.json) — both are
`"private": true` internal tooling, never published.
